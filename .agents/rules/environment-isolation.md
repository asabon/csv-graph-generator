# 環境差異・ホスト固有設定のコミット禁止ルール

## 1. 環境依存ファイル・生成物のコミット禁止
- **禁止事項**:
  - `node_modules/` やローカルの一時キャッシュ・ビルド成果物（`/scratch/`, `coverage/`, `.DS_Store` など）をコミットすることを固く禁止する。
  - Windows/ホスト固有の絶対パス（例: `C:\Users\...`）や環境依存のパスを共有コード・設定ファイル・ドキュメントにハードコードしてコミットしてはならない。
  - 本プロジェクトは `canvas` などネイティブコンパイルが必要な依存関係を含むため、GitHub Actions（Ubuntu / Docker）環境での自動テスト・ビルドを前提としている。ローカル環境依存の成果物が紛れ込まないよう留意すること。

## 2. コミット前の差分検証
- コミット前に必ず `git status` および `git diff` を確認し、意図しない一時ファイルや環境固有の設定が含まれていないことを検証すること。
